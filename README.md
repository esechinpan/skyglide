# SkyGlide — 崖から飛べ

崖から飛び降りてウイングスーツで滑空する、ブラウザで遊べる 3D ゲームです。
Three.js（CDN）＋ ES Modules の純粋な静的サイトで、ビルド工程はありません。

## 遊び方

| 操作 | キーボード | ゲームパッド | タッチ |
| --- | --- | --- | --- |
| ジャンプ / 決定 | Space | A | JUMP ボタン |
| 急降下 / 機首上げ | W / S（↑ / ↓） | 左スティック | 左スティック |
| 旋回 | A / D（← / →） | 左スティック | 左スティック |
| ブースト | Shift | RT / A | BOOST |
| ブレーキ | X | LT / B | BRAKE |
| バレルロール | Q / E | LB / RB | JUMP ボタン（飛行中） |
| カメラ切替 | V | – | – |
| ポーズ | Esc / P | Start | II ボタン |

- 速度が落ちすぎると失速します。急降下で速度を稼ぎ、機首上げで滑空しましょう。
- リングを連続で通過するとコンボ倍率（最大 ×5）。ミスするとコンボ終了。
- 地面スレスレを飛ぶと「スレスレボーナス」が加算されます。
- ゴールゲートをくぐるとクリア。スコアでメダル（★）が決まります。

## やりこみ要素

- **6 つのステージ**：高原の岬 / 赤の峡谷 / 珊瑚の群島 / 灼熱の火山 / 極北の氷河 / 天空の遺跡（星の数で解放）
- **メダル & ミッション**：各ステージに 3 段階のメダルと 3 つのミッション
- **格納庫**：ジェムで 6 種のアップグレード（揚力・旋回・ダイブ・ブースト・マグネット・プロテクター）
- **スキン**：条件を満たすと 7 色のウイングスーツを解放
- **実績 & 統計**：16 種の実績、累計飛行距離などの記録
- **エンドレスモード**：好きな景色で無限に飛び続け、到達距離を競う

セーブデータはブラウザの localStorage に保存されます。

## ローカルで動かす

任意の静的サーバーで配信するだけです。

```bash
python -m http.server 8765
# → http://localhost:8765/
```

## デプロイ（Cloudflare）

公開 URL: https://skyglide.illiameadps07.workers.dev

Cloudflare Workers の静的アセット配信（`wrangler.jsonc` の `assets.directory: "."`）で公開しています。
更新は次のコマンドだけです（初回は `npx wrangler login`）。

```bash
npx wrangler deploy
```

## 構成

```
index.html        エントリ / 画面の DOM
css/style.css     UI・HUD のスタイル
src/main.js       アプリ起動・ループ・画面遷移
src/game.js       1 プレイのセッション（スコア・カメラ・ミッション）
src/player.js     ウイングスーツのモデルと滑空物理
src/terrain.js    バイオームごとの地形生成・チャンクストリーミング
src/deco.js       木・岩・柱などのローポリ装飾と雲
src/course.js     リング・ジェム・ゴール・当たり判定
src/stages.js     ステージ / アップグレード / スキン / 実績の定義
src/save.js       セーブデータ（localStorage）
src/audio.js      WebAudio による効果音と環境音（音声ファイル不要）
src/input.js      キーボード / ゲームパッド / タッチ入力
src/noise.js      シード付きシンプレックスノイズ
```
